O projeto utiliza Supabase para armazenar:

1. Participações diárias dos sorteios.
2. Cadastros dos aniversariantes.

REGRA:

Cada telefone pode participar uma vez por dia.

Para publicar na Vercel:

1. Entre na pasta do projeto.
2. Faça upload para o GitHub.
3. Conecte o repositório à Vercel.
4. Publique.

IMPORTANTE:

Antes de publicar, execute o SQL fornecido para criar
as tabelas no Supabase.
